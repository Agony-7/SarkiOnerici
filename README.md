# SongMates - Şarkı Öneri Uygulaması 🎧
🚀 **Canlı Demo:** [Buraya Tıklayarak Uygulamayı Deneyebilirsiniz](https://sarkionerici.onrender.com)

Bu proje, Yönetim Bilişim Sistemleri (YBS) dersi için hazırlanmış, **Flask** ve **Deezer API** kullanılarak geliştirilmiş modern bir şarkı önerme web uygulamasıdır. 

Kullanıcıların arattığı şarkılara müzikal ve artistik olarak en yakın şarkıları bulur, 30 saniyelik sesli önizlemeleri ve albüm kapaklarıyla birlikte modern bir arayüzde sunar.

## Özellikler ✨
- **Hızlı ve Ücretsiz API:** Açık kaynaklı Deezer API altyapısı sayesinde hiçbir hesap kurulumu veya şifre (API Key) gerektirmez.
- **Canlı Önizleme:** Önerilen her şarkıyı tıklayıp 30 saniye boyunca sayfadan ayrılmadan dinleyebilirsiniz.
- **Glassmorphism Tasarım:** Dış kütüphane kullanılmadan (Pure CSS) yazılmış, cam efektli ve koyu tema ağırlıklı şık arayüz.
- **Anında Yanıt:** Fetch API ile sayfa yenilenmeden asenkron veri çekme işlemi.

## Kullanılan Teknolojiler 💻
- **Backend:** Python, Flask, Requests
- **Frontend:** HTML5, CSS3, JavaScript (Vanilla)
- **Veri Kaynağı:** Deezer Open API

## Nasıl Çalıştırılır? 🚀

Projenin çalışması için bilgisayarınızda Python yüklü olmalıdır.

1. Proje dosyalarını indirin veya klonlayın.
2. Terminalden proje klasörünün içine girin.
3. Gerekli kütüphaneleri yükleyin:
   ```bash
   pip install -r requirements.txt
   ```
4. Uygulamayı başlatın:
   ```bash
   python app.py
   ```
5. Tarayıcınızdan `http://127.0.0.1:5000` adresine giderek uygulamayı kullanmaya başlayabilirsiniz!
